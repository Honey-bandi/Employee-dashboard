# Employee-dashboard
1. Project Title
HR Analytics Dashboard – Employee Headcount & Salary Analysis (Power BI)

2. Short Description
This Power BI dashboard provides an interactive overview of workforce metrics, enabling HR teams and management to monitor employee headcount, average salary, department-wise employee distribution, and salary details. The dashboard uses interactive filters so users can quickly analyze workforce data and make informed decisions.

3. Purpose
Monitor the total employee headcount.
Analyze the average salary across the organization.
Compare employee distribution by department.
View employee salary details by gender.
Support HR decision-making through interactive filtering and visualization.

4. Tech Stack
Power BI Desktop – Dashboard development and visualization
Microsoft Excel – Data source
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – Measures and calculations
Power BI Visuals – Cards, Pie Chart, Table, and Slicers
Data Modeling – Relationships between tables (if applicable)

5. Data Source
Employee HR dataset stored in Microsoft Excel
Dataset includes:
Employee Name
Department
Gender
Salary
Employee ID
Other HR-related attributes used for analysis

6. Feature Highlights
📊 KPI cards showing Total Headcount and Average Salary
🥧 Department-wise employee headcount visualization using a pie chart
📋 Employee salary table with Name, Salary, and Gender
🎯 Interactive filters that update all visuals dynamically
📈 Automatic recalculation of KPIs when filters are applied
🎨 Clean and user-friendly dashboard layout for HR reporting
⚡ Interactive analysis for workforce planning and salary monitoring
📌 Supports quick insights into departmental employee distribution and compensation trends.
